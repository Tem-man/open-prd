# 应用使用率

## 工作流程
为生成一份可用的「应用使用率」分析文档，需要按照以下步骤执行：
1. 明确分析目标与范围，包括统计周期（如近30天）、用户群体（如新用户、老用户）以及功能模块列表。
2. 收集并整理应用埋点数据或运行日志，提取每个功能在统计周期内的触发次数。
3. 统计各功能的使用次数，并计算使用率。使用率计算公式一般为：功能使用率 = 功能使用次数 / 活跃用户数。
4. 进行用户群体对比，分析不同用户群体在功能使用偏好上的差异。
5. 根据使用率数据由高到低进行排序，得到高频功能排行。

## 输出规范
输出内容必须严格遵循「应用使用率」主题，并采用文段形式。具体要求如下：
- 使用语义化 HTML 标签组织内容，包括 `<h2>`、`<h3>`、`<p>`、`<ul>`、`<li>`、`<strong>`。
- 文档结构必须包含「用户群体对比」、「功能使用次数统计」、「高频功能排行」三个核心板块。
- 在「用户群体对比」中，需要用文字描述不同用户群体在功能使用频率上的具体差异。
- 在「功能使用次数统计」中，应使用列表或段落明确列出各功能的使用次数与使用率。
- 在「高频功能排行」中，要按使用率从高到低依次罗列功能，并突出显示排名前三的功能。
- 所有数据与结论必须与「应用使用率」直接相关，不得引入无关内容。

<h3>一、用户群体对比</h3>
<p>按用户类型划分，付费用户的人均日使用次数为23次，显著高于免费用户的12次；付费用户更倾向于使用「数据导出」与「高级筛选」功能，而免费用户则主要集中在「基础编辑」与「在线预览」功能。</p>

<p>在统计周期内，各功能累计使用次数如下：</p>
<ul>

    <li><strong>数据导出功能：</strong>累计使用 30,000 次，使用率 20%。</li>
</ul>

<h3>三、高频功能排行</h3>
<p>根据使用率统计，高频功能排行前三名依次为：</p>
<ul>
