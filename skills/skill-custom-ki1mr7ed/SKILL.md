# 竞品分析

## 指令

请遵循以下规范生成竞品分析模块的PRD内容。

### 输出规范

- 必须包含一个或多个表格，使用 `<table class="prd-table">` 结构，不得使用Markdown原生表格。
- 表格需包含以下列（根据分析对象可微调）：
  - **竞品名称**：清晰标注竞品名称。
  - **核心功能**：列出2~4项该竞品特有的或差异化的功能。
  - **定价模式**：标明收费模式（如免费、订阅制、按量计费、一次性购买等）及大致价位区间。
  - **优势**：1~2句话描述。
  - **劣势**：1~2句话描述。
- 在每个表格后，使用 `<p>` 或 `<ul>` 简要总结该维度的市场格局趋势。
- 整体结构建议分为：**功能对比**、**定价对比**、**优劣势总结**、**市场格局趋势**（可合并到一个表格中，也可分多个表格）。
- 每个表格前使用 `<h3>` 作为标题。
- 所有内容使用中文，避免口语化。

### 输出示例

以下是“功能对比”表格的示例（仅作格式参考，实际内容需根据用户具体产品调整）：

<h3>核心功能对比</h3>
<table class="prd-table">
  <thead>
    <tr>
      <th>竞品名称</th>
      <th>核心功能</th>
      <th>优势</th>
      <th>劣势</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>产品A</td>
      <td>
        <ul>
          <li>实时数据同步</li>
          <li>多端协作编辑</li>
          <li>AI自动分类</li>
        </ul>
      </td>
      <td>协作效率高，生态丰富</td>
      <td>定价较高，学习曲线陡峭</td>
    </tr>
    <tr>
      <td>产品B</td>
      <td>
        <ul>
          <li>离线使用</li>
          <li>轻量级界面</li>
          <li>本地存储优先</li>
        </ul>
      </td>
      <td>隐私性好，价格低廉</td>
      <td>功能单一，扩展性差</td>
    </tr>
  </tbody>
</table>

<p>从功能对比可看出，产品A偏向协作与企业场景，产品B则更注重个人隐私与轻量化。市场趋势表明，混合协作（在线+离线）将成为新的竞争焦点。</p>
