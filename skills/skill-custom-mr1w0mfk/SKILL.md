# 功能频率饼图

## 工作流程
1. 收集各功能名称及其使用次数（或直接接收结构化数据）。
2. 对数据进行校验：所有数值必须为正数，最多保留两位小数。
3. 构造 Mermaid 饼图代码，按输入顺序排列切片（顺时针展示）。
4. 输出 `<div class="mermaid">` 包裹的 Mermaid 语法块，确保可直接渲染。

## 输出规范
- 必须使用 `<div class="mermaid">` 包裹 Mermaid 代码，不可使用 Markdown 代码块。
- 代码块内第一行为 `pie` 关键字，可选用 `showData` 以在图表中显示原始数值。
- 第二行可选，用 `title` 加标题文本。
- 后续每一行定义一个切片：`"标签" : 数值`。
- 示例代码需完整且语法合法。

## 输出示例

<div class="mermaid">
pie showData
    title 功能使用频率统计
    "登录" : 250
    "数据查询" : 430
    "报表生成" : 180
    "设置" : 95
    "导出" : 145
</div>

## 生成规则（必须遵守）
- 图表类型必须为 **Pie Chart（pie）**，以 `pie` 关键字开头。
- 数值必须为**正数**，大于 0，支持最多两位小数，负数会导致渲染错误。
- 可不指定百分比，Mermaid 会自动按数值比例计算各扇区角度。
- 若需显示原始数值，可在 `pie` 后紧跟 `showData`。
- 切片顺序决定顺时针排列方向，先声明的标签先出现在图表顶部附近。
- 标签文本需使用双引号包裹，格式为 `"标签" : 数值`。
- 可选的 `title` 用于设置图表标题，字符串需用双引号。
- 不允许出现空值、非数值字符或未闭合的引号。
