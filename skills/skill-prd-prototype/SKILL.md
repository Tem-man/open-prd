# 原型设计依据生成指南

根据 PRD 大纲提供的关键要点，生成「原型设计依据」章节的 HTML 内容。本章节的首要读者是**原型设计 AI 代理**（其次是人类评审者），因此结构必须严格固定、信息必须具体到可直接据此绘制页面，禁止空泛描述。

---

## 输出结构（六个子章节，顺序与标题层级固定）

所有内容为一个 HTML 片段，不含 `<html>/<head>/<body>` 根标签。每个子章节用 `<div class="prd-subsection">` 包裹，子章节标题一律使用 `<h2>`。

### 1. 产品概述与目标用户

- 一段 3–5 句话的概述：产品是什么、解决什么问题、核心用户是谁、主要使用场景。
- 使用 `<p>` 标签。这一段用于让 AI 代理把握整体基调，必须包含产品形态（Web 管理后台 / 移动端 / 桌面工具等）。

### 2. 页面清单

- 必须使用 `<table>`，表头固定为：`页面名称 | 层级 | 核心目标 | 优先级`
- 「层级」指页面在信息架构中的位置，如：一级页面、二级页面、弹窗/抽屉。
- 「优先级」使用 P0 / P1 / P2。
- 覆盖产品的全部主要页面，通常 4–10 行。

### 3. 页面详情

- 每个页面一个 `<h3>` 标题（标题文字与页面清单中的「页面名称」严格一致），后跟：
  - `<p><strong>布局结构</strong>：…</p>` —— 页面的区域划分（如：顶部筛选栏 + 左侧树 + 右侧表格），具体到方位与组成；
  - `<p><strong>关键组件</strong>：…</p>` —— 逐一列出组件及内容（如：数据表格含 xx 列、操作列含 编辑/删除 按钮）；
  - `<p><strong>交互行为</strong>：…</p>` —— 主要操作的触发与反馈（如：点击「新建」弹出抽屉表单，提交后刷新列表并提示成功）；
  - `<p><strong>异常与空态</strong>：…</p>` —— 空数据、加载失败、无权限等状态的展示。
- 页面顺序与页面清单一致；P0 页面必须完整四项，P1/P2 页面可适当精简交互与异常描述。

### 4. 全局导航与跳转关系

- 必须使用 `<table>`，表头固定为：`起点页面 | 触发动作 | 目标页面`
- 覆盖全局导航（菜单结构）与页面内的关键跳转，通常 5–12 行。

### 5. 设计规范

- 使用 `<ul><li>` 列出，每项给出**具体值**，禁止只写"简洁美观"类描述：
  - 主色 / 成功 / 警告 / 错误色值，按以下优先级确定：
    1. **用户提供**：关键要点或对话中出现品牌色、设计偏好时，必须使用；
    2. **领域推断**：无用户提供时，根据产品领域与目标用户推断合适色值（如医疗→可信蓝绿、金融→稳重深蓝），并给出具体 hex；
    3. **默认值兜底**：实在无据可依时，参考 `#4F46E5` / `#10B981` / `#F59E0B` / `#EF4444`；
  - 背景色层级（与上方色值同一优先级：用户提供 > 领域推断（如深色主题产品用深色背景）> 默认 `#FFFFFF` / `#F8FAFC` / `#F1F5F9`，且需与主色冷暖协调）；
  - 字体族与字号梯度（字体族优先 Inter / PingFang SC / Noto Sans SC 等常见 Web 字体，确保原型编辑器可渲染；字号梯度：标题 18–24px、正文 14px、辅助 12px）；
  - 圆角规范（可按产品气质调整：企业工具宜小、儿童/休闲产品宜大；无特殊气质时参考卡片 8px、小按钮 6px、气泡 12px）；
  - 间距与布局基调（如：卡片间距 16px、页面左右留白 24px）。

### 6. 用户流程与页面映射

- 使用 `<ul><li>`，每条格式：`<strong>流程名称</strong>：页面A → 页面B → 页面C（关键动作简述）`
- 覆盖 2–5 条核心用户流程，与「业务流程」模块呼应但落到页面级。

---

## 生成规则（必须遵守）

- **结构固定**：六个子章节缺一不可，顺序、标题层级、表格表头严格按上方规范。
- **具体可执行**：所有描述必须具体到组件、列名、按钮文案级别，AI 代理将直接据此绘制页面，禁止「合理的导航」「清晰的布局」这类空泛措辞。
- **来源约束**：页面与功能必须来源于关键要点与产品描述，禁止虚构与需求无关的页面。
- **命名一致**：页面名称在「页面清单」「页面详情」「跳转关系」「流程映射」四处必须严格一致。
- **输出纯净**：只输出 HTML 片段，不要输出任何解释文字，不要包裹 Markdown 代码块标记。
