# 墨刀 AI 原型生成智能体——编辑功能设计研究报告

> **研究来源**：墨刀官网 (modao.cc/feature/ai)、站酷专栏、知乎评测、鱼皮AI导航等公开资料  
> **研究时间**：2026-05-30  
> **参考链接**：[https://modao.cc/ai/design/splpderyo2gwp6pw/6a091b4dfed7e9979e4c1d5d](https://modao.cc/ai/design/splpderyo2gwp6pw/6a091b4dfed7e9979e4c1d5d)

## 一、产品定位与核心思路

墨刀 AI Agent 是面向产品经理的专属智能体，其核心设计理念是：

> **"AI 生成原型不是终点，而是可随时编辑、随时推进的起点。"**

与其他仅能一次性输出静态图的 AI 工具不同，墨刀的差异化主张是将 AI 生成的原型图变成**真实可编辑的组件化原型**，从而打通"产品调研 → 原型生成 → 编辑调整 → 文档输出 → 评审交付"的完整链路，无需切换工具。

---

## 二、生成流程概览

```
用户输入（文字 / 草图 / 截图）
        ↓
AI 追问确认需求细节（表单式追问）
        ↓
生成原型大纲（可在此阶段修改方向）
        ↓
确认大纲 → 生成多页面可交互原型初稿
        ↓
进入编辑阶段（双模式编辑）
        ↓
分享 / 导出 / 文档生成 / 代码交付
```

**关键节点**：生成前先给出大纲预览，用户确认无误后再正式生成，减少生成后大幅改动的需求。

---

## 三、双模式编辑设计（核心功能）

墨刀将生成后的编辑分为两大模式，二者互补，覆盖不同粒度的修改需求：

### 3.1 模式一：AI 对话式编辑（轻量调整）

| 维度 | 说明 |
|------|------|
| **入口** | 生成完成后，直接在对话框输入修改指令 |
| **适用场景** | 全局风格调整、局部模块改动、布局重排 |
| **交互方式** | 纯自然语言，无需选中元素 |
| **典型指令** | "把列表改成卡片样式布局"、"主题色改为蓝色"、"继续优化一下界面视觉效果" |
| **能力边界** | AI 可精准定位到目标模块，不影响整体风格；支持多轮对话持续迭代 |

#### 子功能：局部区域选择式对话编辑

- 在生成的页面上**点击选中特定区域/模块**，然后在对话框输入针对该区域的修改意见
- AI 仅修改被选中区域，不影响页面其他部分
- 示例：点击首页顶部区域 → 输入"加我的点赞模块" → AI 精准调整该区域

```
┌─────────────────────────────────────────┐
│  生成的原型页面                           │
│  ┌──────────────────────┐               │
│  │   [选中区域高亮显示]   │ ← 用户点击选中 │
│  └──────────────────────┘               │
│                                         │
│  AI 对话框：输入针对该区域的修改指令       │
└─────────────────────────────────────────┘
```

### 3.2 模式二：导出至墨刀原型手动编辑（精细调整）

| 维度 | 说明 |
|------|------|
| **入口** | 预览界面右上角"导出至墨刀"按钮 |
| **适用场景** | 精细排版、图层调整、添加复杂交互逻辑 |
| **交互方式** | 传统拖拽式原型编辑器 |
| **可编辑内容** | 文本、颜色、图标、组件圆角、尺寸、布局 |

**导出后的保真度承诺**：
- ✅ 文本可改
- ✅ 图层完整（与 AI 生成界面一致）
- ✅ 组件结构保留
- ✅ 交互动效可拓展
- ✅ 动态组件自动转换（如轮播图 → 动态面板，可添加交互逻辑）

---

## 四、直接编辑模式（内联编辑）

除了上述两种主模式，墨刀还提供在 AI 生成结果中**直接切换编辑模式**的能力：

- 在原型预览左上角切换至"编辑模式"
- 直接点选元素，像手动设计一样修改文本、颜色、图标、组件参数
- 生成的页面"不是静态图片，而是由真实组件拼成的可编辑原型"

这是区别于其他 AI 工具（只输出图片或纯代码）的关键技术支撑点。

---

## 五、智能建议机制（主动续写）

每次生成结束后，墨刀 AI 会基于当前项目上下文**主动给出多条可执行的智能建议**：

- 自动分析已有页面逻辑，推断"下一步该做什么"
- 每条建议均为从已有页面自然延伸的行动项（如"补充详情页"、"完善结算流程"）
- 用户一键点击即可继续生成，保持创作节奏不断档

```
生成结束
    ↓
系统自动分析上下文
    ↓
展示 3~5 条智能建议卡片
    ["完善商品列表页"] ["添加用户登录流程"] ["补充支付确认页"] ...
    ↓
用户点击 → 直接触发下一轮生成
```

## 六、生成结果的编辑层次总结

```
第一层：生成前大纲确认（最低成本修改方向）
第二层：AI 全局对话编辑（风格、结构层面调整）
第三层：AI 局部区域选择编辑（模块级精准修改）
第四层：页面内直接编辑模式（元素级手动修改）
第五层：导出至原型编辑器（专业级精细打磨 + 交互逻辑）
```

越往下层，修改颗粒度越细，但自动化程度越低、人工成本越高。整体设计遵循**渐进式编辑**原则，用户可根据需要在任意层级介入。

---

## 七、设计即代码（编辑结果的交付）

墨刀 AI 的编辑流程最终可对接代码交付：

- **原型与代码实时联动**：一边是所见即所得原型，一边是自动对应的 HTML/CSS 代码
- **支持导出 React 或 HTML 代码**：基于设计系统（Ant Design、Material UI 等）生成，可直接交付开发
- **响应式布局输出**：支持指定终端尺寸（手机 / 网页 / 平板），生成响应式代码

## 八、文档编辑联动

原型编辑完成后，墨刀 AI 还提供与文档的联动编辑能力：

| 文档类型 | 能力 |
|----------|------|
| PRD 文档 | 基于原型自动生成功能结构、交互细节说明文档 |
| 交互说明 | 自动梳理页面内布局结构、逻辑关系、上下文关联信息 |
| 文档二次编辑 | 支持自然语言或手动修改，自由调整内容结构 |

## 九、与竞品的核心差异

| 维度 | 纯代码类工具（v0/Bolt） | 纯 UI 类工具 | 墨刀 AI Agent |
|------|------------------------|--------------|----------------|
| 输出物 | HTML/React 代码 | 静态 UI 图 | 可交互多页面原型（组件化） |
| 编辑方式 | 改代码或重新生成 | 重新生成 | 多层渐进式编辑 |
| 局部修改 | 困难 | 不支持 | ✅ 区域选择 + AI 对话 |
| 交互逻辑 | 代码级 | 无 | ✅ 动态面板、跳转逻辑 |
| 团队协作 | 弱 | 弱 | ✅ 云端协作 + 评审 |
| 开发交付 | 直接 | 需重新开发 | ✅ 代码生成 + 组件标注 |

## 十、对本项目的设计启示

结合墨刀 AI 的编辑功能设计，对 **open-prd PRD 生成 Agent** 可参考的设计要点：

1. **PRD 不应是静态文档**：生成后支持对各模块进行单独的 AI 对话式二次编辑，而非整体重新生成
2. **模块级局部编辑**：用户可点击某个 PRD 模块（如"功能清单"、"业务流程图"），针对该模块输入修改指令，AI 仅更新该模块，保留其余内容
3. **生成前大纲确认**：在生成完整 PRD 前先输出结构大纲，用户确认后再生成，降低生成成本
4. **智能续写建议**：PRD 生成完成后，主动给出"建议补充的模块"或"当前文档的潜在风险点"
5. **渐进式交互层次**：AI 对话编辑（轻量）→ 表单式结构编辑（中量）→ 直接文本编辑（精细），覆盖不同用户习惯
